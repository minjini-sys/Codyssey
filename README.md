## 열어보기

1. 저장소를 내려받거나 클론합니다.
2. 각 HTML 파일을 브라우저에서 직접 엽니다. 서버·패키지 설치·로그인이 필요하지 않습니다.
3. 카드 선택 → 등급 버튼으로 이동하고, 새 제목 추가·처음으로·파일 재개방을 확인합니다.

GitHub의 파일 화면은 코드 보기입니다. 실제 동작은 내려받은 HTML을 브라우저에서 확인해야 합니다. 저장은 같은 브라우저의 로컬 저장소를 사용하며 다른 기기로 전달되지 않습니다.

검증은 브라우저가 아닌 DOM·저장 모형에서 수행했습니다. 실제 브라우저의 화면 크기·드래그·파일 재개방 확인은 미실시이며, 미션 1의 두 AI 입력과 검사 방식 차이는 해당 기록에 명시했습니다. 원본 문제를 측정한 항목의 `PASS`는 검사가 실행됐다는 뜻이며 원본 프로그램에 오류가 없다는 뜻이 아닙니다. `detail`에 원본 실패 사례가 기록되어 있습니다.

AI A는 OpenAI Codex, AI B는 Google Gemini입니다. [Gemini 실제 요청](과제/미션1-1/Gemini_실제요청.md)과 [생성 캡처](과제/미션1-1/증빙/Gemini_생성.png)를 포함했습니다. Codex 주요 대화 캡처와 실제 브라우저 관찰 기록은 보완해야 합니다. GitHub에 파일을 올린 사실과 실제 동료평가 PASS는 구분합니다.

`제공자료/샘플`은 비교·검증용 원본입니다. 배포받은 ZIP과 빈 코랩 질문지는 중복 업로드하지 않았습니다. 원본은 수정하지 않았습니다.
