## 직접 확인할 동작

1. **1-1:** A와 B 각각 초기 8개 확인 → 기생충을 S로 이동 → `테스트: 영화` 추가 → 공백만 추가 → 같은 파일 재개방 → 처음으로. 두 파일에 같은 행동을 하고 결과와 선택 이유를 기록합니다. 현재 자동 검증에서는 B의 이동을 함수로 호출했고 A는 모형 이벤트를 사용했습니다. 실제 클릭 비교로 보완해야 합니다.
2. **1-2:** 원본과 수정본에서 영화 8개 모두 클릭·끌기로 이동합니다. `새영화`와 `새 영화`를 추가해 비교합니다. 수정본에서 저장 유지·초기화·기존 정상 영화도 확인합니다.
3. **1-3:** 민수 HTML을 직접 사용해 저장 여부, 빈 카드, 초기화, 좁은 화면을 확인합니다. 받은 AI 검토와 동료 피드백을 그대로 믿지 않고 기록의 판단과 비교합니다.
4. **1-4:** 원본과 기능 추가본에서 이동·추가·미분류 복귀·초기화를 해 봅니다. S/미분류 개수가 0/8 → 1/7 → 추가 후 1/8 → 초기화 0/8인지 확인합니다.
5. 모든 파일을 좁은 화면에서도 확인하고 같은 브라우저에서 재개방합니다. 모형 저장 결과를 실제 브라우저 저장 결과로 바꿔 적지 않습니다.

## 캡처와 평가

- 실제 Codex 대화의 기능 결정·생성·오류 원인·수정·기능 추가 부분을 캡처해 각 미션의 `증빙` 폴더에 추가합니다.
- 기록에 실제 존재하는 캡처 파일명을 기입합니다. 문서로 만든 가짜 채팅 이미지로 대체하지 않습니다.
- 미션마다 최소 1회 동료평가 PASS를 받아야 합니다. 제공 샘플에 쓰인 동료의 PASS 발언은 본인의 실제 평가가 아닙니다.
- 코랩을 실제 진행했다면 질문지를 추가합니다. 입학연수에서는 선택입니다.
