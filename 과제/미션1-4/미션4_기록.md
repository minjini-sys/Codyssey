# 미션 4 기록

검증 범위: 기능 추가와 DOM 모형 회귀 검사 완료. 실제 브라우저 직접 사용은 미실시.

- 사용한 AI: OpenAI Codex. 주요 대화 캡처는 아직 없으며 이 채팅의 기능 선택·변경 설명 화면을 제출 전 캡처해야 함.
- 더한 기능: **각 칸의 영화 개수 표시**.
- 고른 이유: 어느 등급에 몇 편을 넣었고 미분류가 얼마나 남았는지 바로 알 수 있다. 사용자가 기능 선택을 AI에 위임했고, 원본에 있던 `.count` 스타일을 활용해 최소 변경으로 추가했다.
- 원본: `제공자료/샘플/영화_원본.html`은 변경하지 않았다.
- 요청 내용: '영화 티어리스트에 칸별 영화 개수를 추가해 줘. 첨부 기획서의 완성 기준을 모두 유지하고 원래 기능은 바꾸지 마. 수정한 전체 HTML을 줘.'

| 영화_기능추가.html | DOM 모형 검사에서는 발견하지 못함. 실제 브라우저 화면·파일 저장 유지 검증은 미실시 | 각 등급 label 안에 span.count 추가, 미분류 제목의 개수 갱신. 코드 수정 단계 완료, 실사용 확인 대기 |

## 확인 결과

상위 폴더 `검증.cjs`는 브라우저가 아니라 최소 DOM과 저장 모형으로 스크립트를 실행한다.

- 원본과 추가본 모두 초기 8개 이동, 새 영화 추가, 공백 제목 거부, 미분류 복귀, 끌기 이벤트, 저장 모형을 유지한 재실행, 처음으로가 통과했다.
- 개수: 초기 S=0/미분류=8 → 기생충 S 이동 후 1/7 → 새 영화 추가 후 1/8 → 처음으로 후 0/8.
- 기존 이동/저장 함수를 바꾸지 않고 render에 개수 표시만 추가했다.
- 원래 기능이 망가진 증거가 없어 원본으로 돌아가 다시 요청하는 단계는 수행하지 않았다. 일부러 실패본이나 복구 과정을 만들지 않았다.
- 제작 결과물: `영화_기능추가.html`. 실제 브라우저 확인은 남아 있다.
- 코랩·동료평가: 미실시.
