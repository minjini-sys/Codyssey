## 좁히려고 해 본 것과 결과

실제 브라우저 접근이 보안 정책에 의해 차단되어, Node.js에서 원본 스크립트를 실행하고 최소 DOM 모형으로 이벤트와 상태 변화를 검사했다. 모형은 따옴표 없는 HTML 속성값이 공백에서 끝나는 규칙을 반영한다. 실제 브라우저 및 CSS 검증을 대신하지 않는다. 전체 결과는 상위 폴더 `검증결과.json`에 있다.

| 제목 | 원본 버튼 이동 | 수정본 버튼 이동 |
|---|---|---|
| 기생충 | 가능 | 가능 |
| 인터스텔라 | 가능 | 가능 |
| 라라랜드 | 가능 | 가능 |
| 센과 치히로의 행방불명 | 불가 | 가능 |
| 어벤져스: 엔드게임 | 불가 | 가능 |
| 범죄도시 | 가능 | 가능 |
| 타이타닉 | 가능 | 가능 |
| 토이 스토리 | 불가 | 가능 |

추가한 제목도 비교했다. `새영화`, `콜론:테스트`는 원본에서 이동했지만 `새 영화`, `콜론: 테스트`는 이동하지 않았다. 콜론 자체보다 공백이 조건이었다. 원본은 끌기 이벤트에도 잘린 식별자를 전달하여 같은 문제가 나타났고 수정본의 클릭·끌기 이벤트에서는 정상 상태로 이동했다. 실제 마우스로 끌어 놓은 결과는 아직 확인하지 못했다.

## AI가 말한 원인과 확인 결과

원본은 `id`에 제목을 넣고 다음처럼 HTML 문자열을 만들었다.

```js
template.innerHTML = '<button ... data-id=' + item.id + '>' + item.title + '</button>';
```

예를 들어 `data-id=토이 스토리`는 식별자가 `토이`까지만 된다. 원래 상태에는 `토이 스토리`라는 식별자가 있으므로 선택/이동할 영화를 찾지 못한다. 수정본은 문자열 조립 대신 `createElement('button')`, `element.dataset.id = item.id`, `element.textContent = item.title`을 사용했다. 화면과 다른 기능은 유지했다. 제목 속 HTML도 글자로 표시되게 된다.

실제 브라우저에서 확인할 방법: 초기화 → 기생충과 토이 스토리를 각각 클릭하고 S로 이동 → `새영화`와 `새 영화` 추가 후 같은 행동 → 끌기도 반복. 원본에서는 공백 포함 제목만 실패하고 수정본에서는 모두 이동해야 한다.

| 파일명 | 고친 내용 | 다시 해 본 결과 |
|---|---|---|
| 영화_수정1.html | 카드의 식별자·제목을 HTML 문자열 대신 DOM 속성으로 지정 | 모형에서 초기 8개 모두 이동. 공백·콜론·따옴표·태그 형태의 새 제목도 클릭·끌기 이벤트 통과. 저장 모형 재실행, 빈 제목 차단, 초기화 통과 |

- 실제 파일 재개방 후 저장 유지, 좁은 화면, 실제 드래그: 사용자 확인 필요.
- 코랩/동료평가: 진행하지 않음. 제공자료의 질문지는 빈 원본으로 보관.
