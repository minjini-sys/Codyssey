# 학생을 위한 To-do list

## 대상 사용자

- 해야 할 일과 약속을 잊지 않고 관리하려는 대학생과 학생.
- 주로 휴대폰의 웹 브라우저로 사용합니다.

## 사용 목적

- 할 일과 약속을 기록하여 잊어버리는 일을 방지합니다.
- 아직 하지 않은 일과 약속 날짜·시간을 확인합니다.
- 끝낸 일을 체크하여 완료한 일과 남은 일을 구분합니다.

## 화면 구성과 동작

- 첫 화면 맨 위에 페이지 제목과 오늘 날짜, 한 줄 소개 문구가 있고, 그 아래에 할 일 입력란, 선택 사항인 날짜·시간 입력란, ‘추가’ 버튼이 보입니다.
- 내용만 입력해도 할 일을 추가할 수 있습니다. 약속은 날짜와 시간을 함께 지정할 수 있고, 날짜만 지정할 수도 있습니다. 시간만 입력했다면 날짜도 선택하도록 안내합니다.
- 내용을 입력하고 ‘추가’를 누르면 입력한 항목이 아래 목록에 추가되고 입력란이 비워집니다. 빈 내용이나 공백만 입력한 경우에는 추가하지 않고 안내 문구를 표시합니다.
- 안내 문구가 나온 뒤 잘못된 입력을 고치면 ‘추가’나 ‘저장’을 다시 누르지 않아도 안내 문구가 바로 사라집니다. 문제가 남아 있는 동안에는 안내 문구가 유지됩니다.
- 입력 영역 아래에 ‘전체 2개 중 1개 완료’ 같은 요약 문구와 완료율 막대를 둡니다. 할 일이 없으면 요약 문구 대신 시작을 권하는 문구를 보여 줍니다.
- 그 아래에 ‘전체’, ‘미완료’, ‘완료’ 보기 버튼을 두고, 각 버튼 옆에 해당 항목의 개수를 표시합니다. 처음에는 전체 목록을 보여 줍니다.
- 각 항목에는 완료 체크 상자, 할 일 내용, 지정한 날짜·시간, ‘수정’과 ‘삭제’ 버튼이 있습니다. 날짜·시간을 지정하지 않았다면 해당 정보는 표시하지 않습니다.
- 목록은 날짜순으로 보여 줍니다. 날짜가 있는 항목을 이른 날짜부터 위에 두고, 같은 날짜에서는 시간이 없는 항목, 이른 시간 순으로 둡니다. 날짜가 없는 항목은 추가한 순서대로 그 아래에 둡니다. 항목의 날짜·시간을 수정하면 순서도 바로 바뀝니다. ‘미완료’와 ‘완료’ 보기에서도 같은 순서입니다.
- 완료를 체크하면 내용에 취소선이 생기고 글씨가 흐려집니다. 흐려진 글씨도 읽을 수 있도록 색상을 정합니다. 체크를 해제하면 원래 표시로 돌아옵니다.
- ‘미완료’를 누르면 체크하지 않은 항목만, ‘완료’를 누르면 체크한 항목만, ‘전체’를 누르면 모든 항목이 보입니다. 선택한 보기에서 항목을 추가하면 ‘전체’ 보기로 전환해 추가된 항목을 보여 줍니다.
- ‘수정’을 누르면 해당 항목의 내용과 날짜·시간을 바꿀 수 있습니다. ‘저장’을 누르면 변경 사항이 반영되고, ‘취소’를 누르면 기존 내용이 유지됩니다.
- ‘삭제’를 누르면 해당 항목이 목록에서 제거됩니다.
- 할 일이 없거나 선택한 보기에 해당하는 항목이 없으면 빈 목록 안내를 표시합니다.
- 항목을 추가·수정·삭제하거나 완료 상태를 바꾸면 같은 기기·같은 브라우저의 로컬 저장소(localStorage)에 저장합니다. 저장하거나 불러오지 못하면 안내 문구를 표시합니다.
- 추가·수정·삭제·완료 체크를 하면 ‘할 일을 추가했습니다’ 같은 문장을 화면 낭독기에 알립니다.
- 맨 아래 바닥글에 이 브라우저에 자동 저장된다는 것과 알림은 보내지 않는다는 것을 적습니다.
- 휴대폰에서는 입력란, 목록, 버튼을 세로로 배치하고 긴 내용은 줄바꿈합니다.

## 필요한 자료

- 사용자가 직접 입력하는 할 일 내용과 선택한 날짜·시간.
- 각 항목을 구분할 식별자와 완료 여부.
- 버튼 이름과 안내 문구: ‘추가’, ‘전체’, ‘미완료’, ‘완료’, ‘수정’, ‘저장’, ‘취소’, ‘삭제’, ‘할 일을 입력해 주세요’, ‘날짜를 선택해 주세요’, ‘등록된 할 일이 없습니다’, ‘해당하는 할 일이 없습니다’.
- 검증에 사용할 가상 자료: 날짜 없는 ‘과제 제출하기’, 날짜·시간이 있는 ‘스터디 약속’ 등. 실제 친구의 개인정보는 필요하지 않습니다.
- 외부 이미지, 글꼴, API 키는 필요하지 않습니다.

## 필수 기능

- 내용만으로 할 일 추가.
- 선택적으로 날짜·시간 지정 및 표시.
- 완료 체크와 체크 취소, 완료 항목의 취소선·흐린 글씨 표시.
- 항목의 내용과 날짜·시간 수정.
- 항목 삭제.
- 전체·미완료·완료 목록 보기와 보기별 개수, 완료율 표시.
- 날짜순 정렬.
- 같은 기기·같은 브라우저에서 할 일과 완료 상태 저장 및 다시 불러오기.
- 빈 내용 입력 방지와 휴대폰 화면 대응.

## 완료 기준

- 내용을 입력하고 ‘추가’를 누르면 입력한 내용과 일치하는 미완료 항목이 목록에 한 개 추가됩니다. 날짜·시간 없이도 추가됩니다.
- 내용 없이 또는 공백만 입력하고 ‘추가’를 누르면 항목이 추가되지 않고 ‘할 일을 입력해 주세요’가 표시됩니다.
- 약속 내용과 날짜·시간을 입력하고 추가하면 해당 항목에 입력한 날짜·시간이 표시됩니다. 날짜만 지정하면 날짜만 표시됩니다.
- 날짜 없이 시간만 지정하고 추가 또는 수정 저장을 시도하면 저장되지 않고 날짜 선택 안내가 표시됩니다.
- 안내 문구가 나온 상태에서 내용을 적거나 날짜를 고르면 버튼을 다시 누르지 않아도 안내 문구가 사라집니다. 공백만 적으면 안내 문구가 그대로 남습니다.
- 날짜 없는 항목과 날짜 있는 항목을 차례로 추가하면 날짜 있는 항목이 위에 표시됩니다. 날짜 없는 항목을 수정해 더 이른 날짜를 넣으면 그 항목이 위로 올라갑니다.
- 완료를 체크하면 해당 항목에 체크 표시와 취소선이 생기고 글씨가 흐려집니다. 체크를 해제하면 취소선이 없어지고 원래 글씨 색으로 돌아옵니다.
- 미완료 항목 한 개와 완료 항목 한 개가 있을 때 ‘전체’를 누르면 두 개, ‘미완료’를 누르면 미완료 한 개, ‘완료’를 누르면 완료 한 개가 표시됩니다. 버튼 옆 개수는 2, 1, 1이고 요약 문구는 ‘전체 2개 중 1개 완료’입니다.
- ‘완료’ 보기에서 완료 체크를 해제하면 해당 항목이 현재 목록에서 사라지고 ‘미완료’ 보기에서 확인됩니다.
- ‘완료’ 또는 ‘미완료’ 보기에서 새 항목을 추가하면 ‘전체’ 보기로 전환되고 새 항목이 보입니다.
- ‘수정’에서 내용과 날짜·시간을 바꾼 뒤 ‘저장’을 누르면 변경한 값이 목록에 표시됩니다. ‘취소’를 누르면 기존 값이 유지됩니다. 빈 내용으로는 수정 저장되지 않습니다.
- 항목의 ‘삭제’를 누르면 그 항목만 제거되고 다른 항목은 유지됩니다.
- 항목이 없는 목록을 열면 빈 목록 안내가 표시됩니다.
- 일반 브라우징 환경에서 저장을 허용한 같은 기기·같은 브라우저로 같은 HTML 파일을 다시 열면 항목과 완료 상태가 복원됩니다. 수정·삭제한 결과도 복원됩니다.
- 휴대폰 너비 360px 화면에서 가로 스크롤 없이 입력란과 목록을 읽고 추가·체크·수정·삭제 버튼을 사용할 수 있습니다.
- 다른 파일이나 로그인 없이 HTML 파일 하나로 열립니다. CSS와 JavaScript는 HTML 안에 포함하며 외부 이미지·글꼴·라이브러리를 불러오지 않습니다.

## 추가 기능

- 할 일의 중요도 지정.
- 할 일 내용 검색.
- 정렬 기준을 사용자가 고르는 기능(추가한 순서, 날짜순 등).
- 어두운 화면(다크 모드) 지원.

위 기능은 구현하지 않은 이후 확장 후보이며 이번 구현의 완료 조건에는 포함하지 않습니다.

## 한계 및 비목표

1. 자료는 같은 기기·같은 브라우저에만 저장합니다. 로그인, 서버 저장, 기기 간 동기화는 구현하지 않습니다. 브라우저 데이터를 삭제하면 자료가 사라질 수 있으며, 비공개 모드나 저장 제한 환경에서는 재접속 시 복원을 보장하지 않습니다. 로컬 HTML 저장 동작은 사용할 브라우저에서 확인합니다.
2. 날짜·시간은 화면에서 확인하고 순서를 정하는 용도입니다. 알림, 푸시, 외부 캘린더 연동은 구현하지 않으며, 날짜가 지난 항목을 따로 표시하지도 않습니다.
3. 사용자가 직접 입력한 할 일만 관리합니다. API 키나 서버가 필요한 챗봇·AI 자동 추천, 반복 일정 자동 생성은 구현하지 않습니다.

## 검증 방법

- 가상 자료와 예상 결과를 적은 체크표를 준비합니다. 날짜 없는 ‘과제 제출하기’와 날짜·시간이 있는 ‘스터디 약속’을 추가하고, 화면의 내용·날짜·시간을 원본 입력값과 항목별로 대조합니다.
- 위 두 항목의 순서가 ‘스터디 약속’, ‘과제 제출하기’인지 확인합니다. ‘과제 제출하기’를 수정해 ‘스터디 약속’보다 이른 날짜를 넣은 뒤, 화면의 순서를 손으로 날짜순으로 적어 본 순서와 대조합니다.
- 두 항목 중 하나만 완료 처리한 뒤 전체 2개·미완료 1개·완료 1개가 표시되는지 직접 세어 비교하고, 버튼 옆 개수와 요약 문구도 센 값과 같은지 대조합니다. 완료를 취소한 뒤에는 전체 2개·미완료 2개·완료 0개인지 비교합니다.
- 항목 하나를 수정하고 다른 하나를 삭제한 뒤 창을 닫고 같은 브라우저에서 같은 HTML 파일을 다시 엽니다. 남은 항목의 내용·날짜·시간·완료 여부를 닫기 전에 기록한 값과 대조합니다.
- 휴대폰 화면 너비 360px에서 긴 할 일을 입력하고 추가·체크·체크 취소·수정·삭제를 차례로 수행합니다. 가로 스크롤이나 내용 잘림 없이 완료 기준대로 동작하는지 확인합니다.
- 인터넷 연결을 끊은 상태에서 HTML 파일을 열어 추가·수정·삭제·보기 전환을 실행하고, 외부 파일이나 로그인 요청 없이 동작하는지 확인합니다.
