# 내 영화 티어리스트

## 누가 쓰나

- 나와 영화를 좋아하는 친구들

## 무엇을 하려고

- 본 영화를 S·A·B·C 등급으로 나누어 내 취향을 정리합니다.

## 화면과 동작

- 위에 S·A·B·C 칸, 아래에 아직 안 정한 영화 카드를 보여 줍니다.
- 카드를 누르고 등급 글자를 누르거나, 카드를 끌어 놓으면 해당 칸으로 옮겨집니다.
- 제목을 입력하고 ‘추가’를 누르면 아직 안 정한 영화에 카드가 생깁니다.
- 영화 목록과 등급 배치를 브라우저에 자동으로 저장합니다.
- ‘처음으로’를 누르면 처음 영화 목록과 배치로 돌아갑니다.

## 필요한 자료

- 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리

## 완성 기준

- 영화가 한 칸에만 있고, 옮긴 칸에 남습니다.
- 제목을 입력하면 새 영화 카드가 생깁니다.
- 같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다.
- 화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다.
- ‘처음으로’를 누르면 처음 영화 8개가 모두 미분류로 돌아갑니다.
- 외부 파일·로그인·서버 실행 없이 HTML 한 장으로 열립니다.
- 빈 제목은 추가하지 않습니다.


## 추가 기능: 칸별 영화 개수 표시

- S·A·B·C 등급 이름 아래에 각 칸의 영화 개수를 표시합니다.
- 미분류 제목에도 영화 개수를 표시합니다.
- 현재 배치된 영화 목록을 기준으로 개수를 다시 계산합니다.
- 기존 이동·추가·자동 저장·초기화·빈 제목 방지와 화면 대응은 유지합니다.

### 추가 완성 기준

1. 처음으로를 누르면 S/A/B/C는 각각 0편이고 미분류는 8편입니다.
2. 기생충을 S로 옮기면 S는 1편, 미분류는 7편입니다. 클릭 이동과 끌어 놓기 모두 개수가 갱신됩니다.
3. 새 영화 괴물을 추가하면 미분류가 1편 늘어납니다. 빈 제목이나 중복 제목을 거부할 때는 개수가 변하지 않습니다.
4. 등급 사이로 옮기거나 미분류로 되돌리면 이전 칸은 1편 줄고 목적지는 1편 늘어납니다. 같은 칸으로 옮겨도 개수는 변하지 않습니다.
5. 같은 브라우저에서 파일을 다시 열면 저장된 배치에 맞는 개수가 표시됩니다.
6. 추가·이동 후 처음으로를 누르면 초기 영화 8편과 0/0/0/0/8 개수로 돌아옵니다.
7. 원래 기획서의 완성 기준도 모두 다시 확인합니다.
