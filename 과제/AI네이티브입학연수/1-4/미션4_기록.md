# 미션 4 기록

- 사용한 AI 이름 / 주요 대화 캡처 파일명:
  - OpenAI Codex / GPT-6.1 Sol
  - `대화 캡처 이미지/스크린샷 2026-11-07 204345.png`: 칸마다 영화 개수를 보여주는 기능을 요청한 내용과 AI가 기능을 추가하고 확인할 방법을 설명한 내용.
- 더한 기능과 고른 이유:
  - 티어 칸마다 영화 개수를 보여주는 기능을 넣었다. 영화가 많아지면 개수를 직접 세기 힘들고, 내가 좋아하는 영화의 분포가 어떤지 알 수 있기 때문이다.
  - S·A·B·C뿐 아니라 미분류에도 개수를 표시하도록 했다. 어느 등급에 영화가 많이 모였는지, 아직 분류하지 않은 영화가 얼마나 남았는지 바로 볼 수 있게 하려고 했다.
  - 기획서에 개수 표시의 완성 기준을 덧붙이고, 원래 완성 기준도 모두 맞아야 하며 기존 기능은 바꾸지 말라고 요청했다.
  - 처음에는 각 등급이 0편이고 미분류는 8편이어야 한다. 영화를 옮기거나 추가하면 개수도 바뀌고, 다시 열면 저장된 배치에 맞는 개수가 나와야 한다. 처음으로를 누르면 다시 0/0/0/0/8이 되도록 기준을 정했다.

|---|---|---|
| `영화_기능추가.html` | 내가 확인한 범위에서는 맞지 않는 완성 기준이나 기존 기능의 문제를 발견하지 못했다. | **완성.** 개수 표시 기능을 추가한 뒤 기존 기능에 문제가 없어서 추가로 수정하지 않았다. 원본은 그대로 보관했고, 원본으로 돌아가 다시 요청할 필요도 없었다. `영화_기능추가.html`을 완성본으로 정했다. |

- 작업 후 생각:
  - 이번에는 개수를 보여주는 기능이 비교적 간단해서 문제가 생기지 않은 것 같다. 기존 이동이나 저장 방식을 바꾸지 않고 현재 영화 목록에서 개수를 세어 보여주는 부분만 추가한 것도 영향을 준 것 같다. 정확한 원인으로 단정하는 것은 아니고, 이번 작업을 하면서 든 생각이다.

- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유:
  - 같은 개수 표시 기능이라도 영화가 옮겨질 때만 확인하면 새 영화 추가나 초기화 때 숫자가 틀리는 문제를 놓칠 수 있을 것 같다. 다른 사람은 어떤 순서로 확인했는지 이야기해 보고 싶다.
  - 새 기능을 넣으면서 원래 기능이 망가진 적이 있는지, 있다면 언제 멈추고 원본으로 돌아갔는지도 들어보고 싶다.
