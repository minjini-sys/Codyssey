# 민수 님께 드리는 피드백 — 작성 중

## 잘된 점

직접 사용하면서 좋았던 장면을 확인한 뒤 추가할 예정이다. 받은 동료 피드백의 장점을 내가 직접 확인한 것처럼 옮겨 적지는 않았다.

## 고치면 좋을 점

### 1. 화면 폭이 좁아져도 오른쪽이 잘리지 않으면 좋겠다

- **본 것:** 브라우저 화면 폭을 좁혔더니 페이지의 오른쪽이 잘려 내용을 전부 볼 수 없었다.
- **기준:** 기획서의 ‘화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다’라는 완성 기준에 맞지 않았다.
- **제안:** 화면 폭에 맞춰 페이지 너비가 줄어들고, 입력칸과 버튼도 필요한 경우 줄바꿈되도록 바꾸면 좋겠다. 수정한 뒤에는 좁은 화면에서도 오른쪽 내용과 버튼을 전부 보고 사용할 수 있는지 확인하면 좋겠다.

## 추가로 확인하고 싶은 점

- 미분류가 아래에 있어서 위쪽 등급까지 끌기 어렵다는 동료 의견에는 공감한다. 다만 어떤 화면 크기에서 어려웠는지, 기존의 ‘카드 선택 → 등급 누르기’ 방식도 사용했는지 먼저 확인하고 싶다.
- 클릭 이동은 이미 구현되어 있어서 새로 추가할 기능은 아니다. 직접 사용해 본 뒤, 그 방법을 찾기 어렵다면 이동 안내를 더 눈에 띄게 하거나 영화 목록의 위치를 조정하는 제안을 구체화하고 싶다.

아직 클릭 이동의 직접 사용 결과와 잘된 점을 보충해야 하는 초안이다.
