# 민수 님께 보내는 피드백

잘된 점: S·A·B·C 칸마다 색과 등급 글자가 달라서 구별하기 좋았어요. 영화를 추가한 뒤 ‘처음으로’를 누르니 추가한 영화는 사라지고 처음 영화 8개가 모두 미분류로 돌아왔어요. 이 부분은 기획서대로 잘 작동했어요.

고치면 좋을 점

1. 본 것: 영화를 추가하고 등급을 정한 뒤 같은 브라우저에서 같은 파일을 다시 열었더니, 추가한 영화와 정한 등급이 사라지고 처음 상태로 돌아왔어요.

   - 기준: 기획서의 “같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다.”
   - 제안: 영화 목록과 등급을 브라우저에 저장하고, 파일을 다시 열 때 불러오면 좋겠어요. 그러면 정리한 취향을 다음에도 이어서 볼 수 있을 것 같아요.

2. 본 것: 화면 폭을 좁혔더니 오른쪽 내용이 잘려서 화면 전체를 볼 수 없었어요.

   - 기준: 기획서의 “화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다.”
   - 제안: 화면 폭에 맞게 전체 너비가 줄어들고, 입력창과 버튼도 좁은 화면 안에 들어오도록 배치를 바꾸면 좋겠어요.

3. 본 것: 미분류 목록이 S·A·B·C 칸 아래에 있어요. 동료도 여기서 S칸까지 카드를 끌어 올릴 때 화면을 함께 올려야 해서 불편했다고 했어요.

   - 기준: 기획서에 목록 위치를 바꿔야 한다는 조건은 없지만, 영화를 등급별로 나누는 핵심 동작을 더 편하게 할 수 있으면 좋겠어요.
   - 제안: 미분류 목록을 등급 칸 위에 두는 배치를 검토해 주세요. 이미 있는 ‘카드 선택 후 등급 글자 누르기’ 방법도 목록 가까이에 안내하면 이동 방법을 찾기 쉬울 것 같아요.

4. 본 것: HTML 코드를 확인하니 입력값의 앞뒤 공백만 없애고 빈 제목인지 검사하지 않은 채 카드를 추가하고 있어요. 빈 제목이나 공백만 입력해도 글자 없는 카드가 생기는 구조예요.

   - 기준: 기획서에 빈 제목 금지가 명시돼 있지는 않지만, 제목이 없으면 어떤 영화인지 구별하기 어려워요.
   - 제안: 빈 제목이나 공백만 입력했을 때는 카드를 추가하지 않고 “영화 제목을 입력해 주세요”라고 안내하면 좋겠어요.
