# 미션 3 기록

## 직접 확인한 내용

- 민수의 기획서와 영화 티어리스트를 읽어보고 화면을 확인했다.
- 화면 폭을 좁히면 오른쪽이 잘렸다. 기획서에는 화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있어야 한다고 되어 있어서, 이 완성 기준에는 맞지 않는다고 판단했다.
- 동료 피드백에서 UI와 위쪽 등급으로 끌어 올리기 어렵다는 의견은 반영할 만하다고 생각했다.
- 처음에는 끌어 놓기 외에 누르기 방식도 추가하면 좋겠다고 생각했다. 그런데 AI가 코드를 확인해 보니 카드 선택 후 등급을 누르는 기능은 이미 있었다. 그래서 새로 추가하자는 제안보다는 기존 클릭 이동을 직접 확인하고, 안내와 배치를 개선하자는 방향으로 정리했다. 클릭 이동의 실제 사용 결과는 아직 기록하지 않았다.
- 화면을 좁힌 정확한 폭과 드래그를 직접 해 본 구체적인 장면은 아직 기록하지 않았다.

## 받은 의견에 대한 판단

| 받은 의견 | 판단 | 이유 또는 되물을 질문 |
|---|---|---|
| 휴대폰으로 열면 불편하다 | 반영 — 화면 잘림에 해당하는 부분 | 직접 화면 폭을 좁혔을 때 오른쪽이 잘리는 것을 확인했다. 기획서의 좁은 화면 완성 기준에도 맞지 않는다. |
| 미분류에서 위쪽 S칸까지 끌어 올리기 어렵다 | 되묻기 — 개선 방향에는 동의 | 반영할 만한 의견이라고 생각한다. 다만 내 직접 사용 장면은 아직 기록하지 않았다. 어떤 화면 크기에서 어려웠는지, 카드 선택 후 등급을 누르는 방식도 사용했는지 물어보고 배치 변경을 판단하고 싶다. |
| 카드 이동이 처음에는 헷갈린다 | 되묻기 | 카드를 고르는 단계가 헷갈렸는지, 등급을 누르는 단계가 헷갈렸는지 물어보고 싶다. 기존 클릭 이동 방법을 찾기 어려웠다면 안내를 개선할 수 있다. |

## 아직 확인할 내용

- 클릭 이동을 직접 해 보고 실제 결과 적기.
- 직접 사용해 보니 좋았던 점을 구체적인 행동과 함께 적기.
- 받은 AI 검토와 나머지 동료 의견도 하나씩 확인하고 반영·보류·되묻기를 정하기.
- 받은 의견에 없던 발견이 있는지 확인하기. 화면 잘림은 동료의 휴대폰 불편 의견과 관련되므로 완전히 새로운 발견이라고 단정하지 않기.

현재는 직접 확인한 화면 잘림과 일부 동료 의견에 대한 판단을 기록한 단계다. 모든 항목을 확인하거나 동료평가를 완료한 상태는 아니다.
