# 미션 3 기록

직접 확인한 결과와 기획서·HTML 코드를 비교해 민수의 입장에서 판단했다. 아래에서 코드로 확인한 내용은 따로 표시했다. ‘반영’은 앞으로 개선하거나 유지할 방향을 정했다는 뜻이며, HTML 수정까지 마친 것은 아니다.

| 받은 의견 | 직접 해 본 결과 | 반영 / 보류 / 되묻기 | 이유 (되묻기라면 물을 질문) |
|---|---|---|---|
| AI: 저장 기능이 없다. | 같은 브라우저에서 같은 파일을 다시 열어도 추가한 영화와 정한 등급이 유지되지 않았다. 코드에서도 페이지를 열 때마다 처음 영화 8개를 미분류로 만드는 것을 확인했다. | 반영 | 내 취향을 정리한 결과를 다음에도 볼 수 있어야 한다. 기획서의 완성 기준이므로 영화 목록과 등급을 저장하고 다시 불러오도록 고치겠다. |
| AI: ‘처음으로’가 직접 추가한 영화를 지우지 않는다. | 영화를 추가한 뒤 ‘처음으로’를 누르니 추가한 영화도 사라졌다. 처음 영화 8개만 모두 미분류로 돌아왔다. | 보류 | AI의 지적이 실제 동작과 달랐다. 기획서의 ‘처음 영화 목록과 배치로 돌아갑니다’대로 작동하므로 이 의견에 따른 수정은 하지 않겠다. |
| AI: 빈 제목을 막지 않아 기획서를 어긴다. | 코드상 제목의 앞뒤 공백을 없애지만, 빈 값인지 검사하지 않고 카드를 추가한다. 따라서 빈 제목이나 공백만 입력해도 글자 없는 카드가 생기는 구조다. | 반영 | 빈 제목 금지가 기획서에 명시된 것은 아니므로 ‘기획서를 어긴다’는 설명에는 동의하지 않는다. 다만 제목 없는 카드는 어떤 영화인지 알 수 없으므로 추가를 막고 안내하도록 개선하겠다. |
| AI: 이 세 가지 외에는 완성 기준을 잘 지킨다. | 화면 폭을 좁히니 오른쪽이 잘렸다. 코드에서도 화면 너비가 960px로 고정돼 있고 가로 넘침을 숨기는 것을 확인했다. | 보류 | 좁은 화면에서도 내용을 볼 수 있어야 한다는 완성 기준을 충족하지 못했다. AI의 전체 평가를 그대로 받아들이지 않고, 화면 잘림도 수정 항목에 넣겠다. |
| 동료: 등급마다 색이 달라 어느 칸인지 한눈에 들어온다. | S·A·B·C에 서로 다른 색과 등급 글자가 적용돼 있다. 동료가 말한 장점을 확인할 수 있었다. | 반영 | 등급을 쉽게 구별하는 데 도움이 되므로 화면을 개선할 때도 등급별 색과 글자를 유지하겠다. |
| 동료: ‘8편 중 3편 나눔’처럼 진행 상황이 보여 좋다. | 코드에서 전체 영화 수와 미분류가 아닌 영화 수를 세어 표시하는 것을 확인했다. | 반영 | 아직 얼마나 남았는지 알 수 있어 유용하다. 영화 추가와 이동에 따라 숫자가 바뀌는 표시를 유지하겠다. |
| 동료: 끌어 놓을 때 칸 색이 바뀌어 놓을 위치를 알 수 있다. | 코드에서 카드를 끌어 올린 칸의 배경색을 바꾸고, 칸을 벗어나거나 놓으면 되돌리는 것을 확인했다. | 반영 | 이동할 위치를 알려 주는 표시이므로 유지하겠다. |
| 동료: 휴대폰으로 열면 불편하다. | 화면 폭을 좁혔을 때 오른쪽 내용이 잘리는 것을 확인했다. | 반영 | 동료의 불편에 동의하며, 기획서의 완성 기준에도 해당한다. 화면 너비에 맞게 배치가 줄어들고 내용이 보이도록 고치겠다. |
| 동료: 카드 옮기는 것이 처음에는 헷갈렸다. | 카드 선택 후 등급 글자를 누르는 기능과 끌어 놓는 기능은 코드에 모두 있다. 다만 동료가 어느 단계에서 헷갈렸는지는 의견만으로 알 수 없다. | 되묻기 | “처음에 카드를 선택하는 방법이 헷갈렸나요, 선택한 뒤 등급 글자를 눌러야 한다는 점이 헷갈렸나요? 상단의 이동 안내는 눈에 들어왔나요?” 답을 듣고 안내 문구와 위치를 정하겠다. |
| 동료: 미분류가 맨 아래여서 S칸까지 끌어 올리기 어렵다. 영화 목록이 위나 옆에 있으면 좋겠다. | 미분류 목록은 S·A·B·C 네 칸 아래에 있다. S칸까지 이동 거리가 길고 화면을 함께 올려야 한다는 동료의 사용 결과에 동의한다. | 반영 | 영화를 나누는 핵심 동작을 편하게 만들 필요가 있다. 미분류 목록을 위에 두는 배치를 먼저 검토하고, 카드 선택 후 등급을 누르는 기존 방법도 쉽게 알 수 있게 안내하겠다. |
| 동료: 카드 색이 칙칙하다. | 카드에는 회색 계열의 배경이 적용돼 있다. 동료가 느낀 인상은 이해하지만 내가 원하는 색상 방향은 아직 정하지 않았다. | 보류 | 우선 저장과 좁은 화면 문제, 이동 편의성을 개선하겠다. 카드 색은 이후 제목이 잘 읽히고 등급 색과 어울리는 방향으로 검토하겠다. |
| 동료: 영화 포스터가 같이 나오면 더 보기 좋겠다. | 현재 카드는 영화 제목만 보여 준다. 포스터는 기획서의 필요한 자료와 완성 기준에 포함돼 있지 않다. | 보류 | 포스터는 영화를 알아보는 데 도움이 되지만, 우선 제목으로 영화를 분류하는 기능을 완성하겠다. HTML 한 장으로 여는 조건과 이미지 준비 방법도 고려해 다음 개선 때 검토하겠다. |
| 동료: 아쉬운 영화를 넣을 필요가 없으니 C칸은 없어도 된다. | C칸은 ‘아쉬움’으로 표시되며 기획서에도 S·A·B·C 네 등급이 명시돼 있다. | 보류 | 내 목적은 본 영화의 취향을 정리하는 것이다. 아쉬웠던 영화도 기록해야 취향을 비교할 수 있으므로 C칸을 유지하겠다. 동료의 취향이 틀렸다는 뜻은 아니다. |
| 동료: 큰 문제는 없으니 PASS를 주겠다. | 동료는 사용 후 PASS로 평가했다. 다만 내가 확인한 결과 저장과 좁은 화면에 관한 완성 기준은 충족하지 못했다. | 보류 | 동료의 긍정적인 평가는 고맙지만, 내 기획서 기준으로는 아직 완성으로 판단하지 않겠다. 두 문제를 고친 뒤 완성 기준을 다시 확인하겠다. |

- 아무도 말하지 않았는데 내가 찾은 것: AI가 ‘이 세 가지 외에는 완성 기준을 잘 지킨다’고 했지만, 좁은 화면에서 오른쪽이 잘리는 기준 미충족을 빠뜨렸다.
