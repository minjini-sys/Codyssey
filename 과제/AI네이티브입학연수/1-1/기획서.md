# 내 영화 티어리스트

## 1. 누가 쓰나

- 나와 영화를 좋아하는 친구들이 각자 자신의 영화 티어리스트를 만듭니다.
- 첫 버전은 개인이 자기 기기에서 사용합니다. 회원가입과 다른 사람의 티어리스트를 온라인으로 보는 기능은 이후에 추가합니다.

## 2. 무엇을 하려고

- 내가 본 영화를 개인적인 재미와 취향, 친구에게 추천하고 싶은 정도에 따라 나눕니다.
- 영화 제목과 포스터를 보면서 내 취향을 정리하고, 친구들과 영화에 대해 이야기할 때 참고합니다.
- 등급은 높은 순서대로 **인생영화 / 추천 / 보통 / 아쉬움**으로 정합니다.

## 3. 화면과 동작

### 화면 구성

- 위에서부터 인생영화, 추천, 보통, 아쉬움 칸을 배치합니다.
- 등급 칸 아래에는 아직 등급을 정하지 않은 영화를 두는 **미분류** 칸을 배치합니다.
- 처음에는 아래에 정한 영화 8편이 모두 미분류에 있습니다.
- 처음 영화 8편의 카드에는 제목과 포스터를 함께 표시합니다.
- HTML·CSS·JavaScript와 초기 영화 8편의 포스터를 HTML 파일 하나에 포함합니다. 외부 파일·로그인·서버 실행 없이 파일을 브라우저에서 바로 열어 사용하며, 인터넷 연결 없이도 포스터와 기본 기능을 사용할 수 있습니다.
- 새 영화 제목을 입력하는 칸과 추가 버튼을 제공합니다.
- 휴대폰에서도 내용과 버튼이 화면 오른쪽에서 잘리지 않도록 화면 폭에 맞춰 배치합니다.

### 영화 이동

- 영화 카드를 원하는 등급 칸으로 드래그하면 그 칸으로 이동합니다.
- 드래그 대신 카드를 선택한 뒤 등급 버튼을 눌러도 이동합니다.
- 등급이 정해진 영화도 다른 등급이나 미분류로 다시 옮길 수 있습니다.
- 영화 한 편은 항상 한 칸에만 존재합니다.
- 휴대폰에서는 카드 선택 후 등급 버튼을 누르는 방식으로 이동할 수 있어야 합니다.

### 영화 추가와 삭제

- 목록에 없는 영화는 제목만 입력해 추가할 수 있습니다.
- 새 영화는 미분류 칸에 배치하고, 포스터 대신 제목이 적힌 기본 카드를 보여줍니다.
- 제목 앞뒤의 공백은 제거합니다. 빈 제목이나 공백만 있는 제목은 추가하지 않고 이유를 안내합니다.
- 앞뒤 공백을 제거한 제목이 기존 목록의 제목과 같으면 중복으로 추가하지 않고 안내합니다.
- 영화 한 편을 개별적으로 삭제할 수 있습니다.

### 저장과 초기화

- 추가·삭제한 영화와 현재 등급 배치를 브라우저에 자동 저장합니다.
- 같은 기기·같은 브라우저에서 같은 페이지를 다시 열면 마지막 상태를 불러옵니다. 브라우저의 저장 데이터를 삭제하지 않은 경우를 기준으로 합니다.
- 첫 버전에서는 다른 기기·다른 브라우저로 데이터를 동기화하거나 다른 사람에게 온라인으로 공유하지 않습니다.
- **처음으로** 버튼을 누르면 전체 초기화 여부를 확인합니다.
- 확인하면 사용자가 추가한 영화와 기존 배치를 지우고, 처음 영화 8편을 모두 미분류로 복원합니다. 삭제했던 초기 영화도 복원합니다.
- 취소하면 현재 상태를 유지합니다.

## 4. 필요한 자료

### 처음 사용할 영화 8편

1. 기생충
2. 인터스텔라
3. 라라랜드
4. 센과 치히로의 행방불명
5. 어벤져스: 엔드게임
6. 범죄도시
7. 타이타닉
8. 토이 스토리

### 이미지 자료

- 위 영화 8편에 대응하는 포스터 이미지가 필요합니다.
- 현재 포스터 이미지 파일과 출처는 준비되지 않았습니다. HTML 제작 전에 사용할 이미지와 출처를 확인하고, 이미지를 HTML 내부에 포함합니다. 별도 이미지 폴더나 외부 이미지 주소에 의존하지 않습니다.
- 사용자가 새로 추가하는 영화는 포스터 없이 기본 카드로 표시합니다.

## 5. 완성 기준

아래 기준을 브라우저에서 직접 확인합니다. 두 AI가 만든 HTML에도 같은 행동을 해 보고 결과를 비교합니다.

| 번호 | 확인할 행동 | 기대 결과 |
|---|---|---|
| 1 | 저장된 기록이 없는 상태에서 처음 열기 | 네 등급 칸은 비어 있고, 미분류에 초기 영화 8편이 제목·포스터와 함께 표시됩니다. |
| 2 | 기생충을 미분류에서 인생영화로 드래그하기 | 인생영화에 기생충이 한 번만 표시되고 미분류에서는 사라집니다. |
| 3 | 인터스텔라 카드를 선택한 뒤 추천 버튼 누르기 | 인터스텔라가 추천 칸으로 이동하고 다른 칸에 중복되지 않습니다. |
| 4 | 등급이 정해진 영화를 다른 등급과 미분류로 옮기기 | 선택한 목적지로 이동하고 이전 칸에는 남지 않습니다. |
| 5 | 기존 목록에 없는 영화 제목을 입력하고 추가하기 | 미분류에 제목이 적힌 기본 카드가 하나 생깁니다. |
| 6 | 빈 제목 또는 공백만 입력해 추가하기 | 영화가 추가되지 않고 입력 안내가 표시됩니다. |
| 7 | 기존 영화 제목을 입력해 추가하기. 앞뒤에 공백을 붙인 경우도 확인하기 | 중복 카드가 생기지 않고 중복 안내가 표시됩니다. |
| 8 | 영화 한 편 삭제하기 | 해당 영화만 목록에서 사라지고 다른 영화와 배치는 유지됩니다. |
| 9 | 영화 추가·이동·삭제 후 페이지를 닫았다가 같은 기기·브라우저에서 다시 열기 | 추가한 영화, 삭제 상태, 등급 배치가 마지막 상태대로 유지됩니다. |
| 10 | 처음으로 버튼을 누른 뒤 취소하기 | 현재 영화 목록과 배치가 유지됩니다. |
| 11 | 처음으로 버튼을 누른 뒤 초기화에 동의하기 | 추가 영화가 사라지고, 삭제했던 초기 영화를 포함한 처음 8편이 모두 미분류로 돌아옵니다. 다시 열어도 초기화한 상태가 유지됩니다. |
| 12 | 화면 폭 360px와 390px에서 페이지 확인하기 | 제목·입력칸·버튼·영화 카드를 오른쪽 잘림 없이 확인할 수 있습니다. |
| 13 | 휴대폰에서 카드를 선택하고 등급 버튼 누르기 | 드래그를 사용하지 않아도 원하는 등급으로 영화가 이동합니다. |
| 14 | 별도 이미지 폴더 없이 HTML 파일 하나만 두고, 인터넷 연결을 끈 상태에서 브라우저로 열기 | 로그인이나 서버 실행 없이 초기 영화 8편의 제목·포스터가 표시되고, 이동·추가·삭제·초기화 기능이 동작합니다. |

회원가입과 온라인 공유는 이번 버전의 완성 기준에 포함하지 않습니다.
