  - `대화 캡처 이미지/claudecode.png`: 같은 기획서로 HTML을 만들어달라고 요청한 내용. 현재 캡처에는 생성 답변이나 수정 대화는 포함되어 있지 않다.
- AI가 물어서 내가 정한 것:
  - GPT-6.1 Sol에게 바로 만들지 말고 뭐가 필요한지 먼저 질문해달라고 했다. 한 번에 서너 개씩 질문을 받고 답하면서 누가 쓰는지, 목적, 화면과 동작, 필요한 자료, 완성 기준을 정했다.
  - 나와 친구들이 각자 자기 티어리스트를 만들고, 개인적인 재미와 취향, 친구에게 추천하고 싶은 정도로 영화를 나누기로 했다. 등급도 S·A·B·C 대신 내가 알아보기 쉬운 인생영화·추천·보통·아쉬움으로 정했다.
  - 처음에는 친구들도 봐야 하니까 회원가입과 온라인 공유가 필요할 것 같았다. 그런데 AI가 브라우저 저장과 온라인 공유의 차이를 설명해줘서, 첫 버전은 각자 자기 기기에서 쓰고 온라인 기능은 나중에 추가하기로 했다.
  - 영화는 처음 8편을 미분류에서 시작하고 제목과 포스터를 같이 보여주기로 했다. 이동은 드래그를 기본으로 하되, 휴대폰에서도 쓸 수 있도록 카드를 선택하고 등급 버튼을 누르는 방법도 넣기로 했다.
  - 목록에 없는 영화는 제목만 입력해 추가하고, 빈 제목과 중복 제목은 막기로 했다. 영화 개별 삭제와 확인창을 거치는 전체 초기화도 넣기로 했다. 추가·삭제한 영화와 배치는 같은 기기·같은 브라우저에서 다시 열어도 유지하도록 했다.
  - 이 답변을 다섯 항목의 `기획서.md`로 정리했다. 예시와 비교했을 때 HTML 한 장으로 실행한다는 조건이 빠져 있어서, 포스터도 HTML 안에 포함하고 인터넷 없이 사용할 수 있게 해달라고 했다.

- 선택한 파일명과 고른 이유:
  - 두 초안 중에서는 `영화_claudecode_초안.html`을 선택했다. 내가 사용해 봤을 때 `영화_codex_초안.html`보다 기능이 더 잘 되었고, 실제 포스터로 바꾸면 내가 원하는 결과에 더 가까울 것 같았기 때문이다.
  - Codex 초안은 포스터는 잘 나왔지만 드래그 등에서 불편한 점이 있었다. Claude Code 초안은 내가 확인한 기능은 되었지만 실제 포스터가 아니라 일러스트가 들어가 있어서, 이 부분을 고치는 방향으로 진행했다.
  - 수정본은 초안을 덮어쓰지 않고 `영화_claudecode_수정본.html`로 따로 남겨두었다.

- 고치지 않았다면 그대로 둔 이유:
  - 이번에는 선택한 Claude Code 초안의 포스터를 수정했기 때문에 해당하지 않는다. Codex 초안은 두 AI의 처음 결과를 비교할 수 있도록 그대로 남겨두었다.

  - 처음에는 회원가입과 온라인 공유까지 넣으려고 했지만 나중으로 미뤘다. 다른 사람은 첫 버전의 범위를 어떻게 정했는지도 들어보고 싶다.
