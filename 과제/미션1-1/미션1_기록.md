# 미션 1 기록

검증 범위: 제작과 DOM 모형 비교를 완료했다. 실제 브라우저 비교와 동료평가는 아직 수행하지 않았다.

- AI A: OpenAI Codex(이 채팅). 생성 파일 `영화_A_초안.html`. 세부 모델 표시를 별도로 확인하지 않았다. 이 채팅의 주요 대화 캡처는 미첨부.
- AI B: Google Gemini, 화면에 표시된 모드는 '자동 모드'. 세부 모델 버전은 표시되지 않음. `영화_B_초안.html`은 Gemini에서 내려받은 원본을 그대로 복사했다. 대화: https://gemini.google.com/app/40eacff869aaa7dd
- B 주요 캡처: `증빙/Gemini_생성.png`. 생성 요청 원문: `Gemini_실제요청.md`.
- 두 결과의 공통 기준: `기획서.md`. A는 이 채팅에서 확인한 동일한 요구조건으로 제작했고 B는 그 조건을 다섯 항목 기획서로 전달했다. 요청 메시지를 두 서비스에 글자 단위로 동일하게 복사한 실험은 아니다. 같은 기획 조건은 전달했지만, 동일 문장을 복사한 실험과 구분한다.

## AI가 물어서 사용자가 정한 것

AI가 'S/A/B/C/D, 제목 직접 추가, 버튼 이동, 브라우저 자동 저장의 개인용으로 진행할지' 물었고 사용자는 '이 구성으로 진행'이라고 답했다. 다른 회사 AI에 같은 조건을 전달하는 것도 사용자가 허용했다. 질문을 여러 차례 주고받았다고 꾸미지 않았다. 초기 영화 8개와 초기화는 제공 예시를 바탕으로 정했다.

제공 예시와 비교: 예시는 S/A/B/C 네 칸과 클릭·끌기 모두를 제안한다. 이번 사용자 결정은 D까지 다섯 등급이며 버튼 이동을 필수로 정했다. 나머지 추가·저장·초기화·단일 HTML·한국어 조건은 유지했다.

## 같은 조건 비교

아래는 실제 브라우저 결과가 아니라 Node.js DOM/저장 모형으로 얻은 결과다. B의 이동 검사는 함수 호출, A는 카드·등급 이벤트 모형으로 검사했으므로 동일한 실제 클릭 실험은 아직 아니다.

| 비교 조건 | 기대 | A 결과 | B 결과 |
|---|---|---|---|
| 최초 실행 | 8개 미분류 | 8개 | 8개 |
| 기생충을 S로 이동 | S에 한 번만 존재 | 통과 | 통과 |
| `테스트: 영화` 추가 | 9개 | 통과 | 통과 |
| 같은 저장 모형으로 새 실행 | 배치와 새 제목 유지 | 통과 | 통과 |
| 공백만 추가 | 개수 불변 | 통과 | 통과 |
| 처음으로 | 초기 8개 복원 | 통과 | 통과 |
| 화면을 좁히고 파일 재개방 | 잘림 없음·실제 저장 유지 | 미확인 | 미확인 |

## 결과물 선택과 이유

- 선택한 파일: `영화_A_초안.html`.
- 이유: 선택한 카드 → 등급 버튼이라는 흐름이 단순하고, 삭제·키보드 단축키 등 미요청 기능이 없다. 저장 실패 안내와 저장 데이터 형태 검사도 있다. B는 카드마다 등급 버튼을 제공하고 삭제·단축키·초기화 확인창을 추가했다. 이는 B의 구현 선택이며 요구조건과 추가 기능을 구분했다.
- A를 선택한 근거는 현재 코드 구성과 모형 검사다. 실제 브라우저에서의 사용성 우열은 아직 판단하지 않았다.

| 파일명 | 고친 내용 | 고친 이유 | 다시 확인한 결과 |
|---|---|---|---|
| 영화_A_초안.html | 최초 제작 중 저장 실패 메시지 문구 정리 | 한국어 안내 일관성 | 최종 최초 버전 모형 검사 통과 |

- 생성 후 별도 수정본은 만들지 않음. 브라우저 결함이 없음을 확인했다는 뜻은 아니다.
- 실제 동료 비교·코랩·PASS: 미실시.
- 보완할 항목: A 주요 대화 캡처, 같은 행동으로 수행한 실제 브라우저 비교 기록, 동료평가 PASS.
