다음 기획서대로 HTML·CSS·JavaScript가 모두 들어 있는 HTML 파일 하나를 만들어 줘. 외부 파일이나 서버 없이 브라우저에서 바로 열리게 하고, 화면 문구는 한국어로 써 줘. 완성된 .html 파일로 제공해 줘. 코드 전체를 코드블록 하나에 넣어 줘.

# 내 영화 티어리스트
## 누가 쓰나
본 영화를 정리하려는 나 개인. 친구와 이야기할 때 화면을 보여 줄 수 있다.
## 무엇을 하려고
영화 제목을 S/A/B/C/D 등급으로 분류해 내 취향을 정리한다.
## 화면과 동작
S/A/B/C/D 칸과 미분류 칸. 영화 카드를 선택한 뒤 등급 버튼을 눌러 이동. 미분류로도 되돌릴 수 있다. 제목을 직접 입력하고 추가 버튼 또는 Enter로 미분류에 추가. 같은 브라우저에 자동 저장. 처음으로 버튼으로 초기 영화 8개를 미분류로 복원. 회원가입·온라인 공유·외부 이미지·서버 없음. 드래그는 필수 아님.
## 필요한 자료
기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리.
## 완성 기준
1. 초기 8개가 미분류.
2. 기생충을 선택해 S 버튼을 누르면 S에만 존재하고 다른 등급·미분류로 다시 이동 가능.
3. 콜론·공백 포함 제목을 포함하여 모든 영화 이동 가능.
4. 새 제목 추가. 공백만 입력하면 추가하지 않고 안내.
5. 같은 브라우저에서 같은 파일 재개방 시 영화와 배치 유지.
6. 처음으로로 초기 8개만 미분류.
7. 좁은 화면에서도 내용과 버튼이 잘리지 않음.
8. 한국어, 단일 HTML, 외부 요청 없이 파일로 열림.
